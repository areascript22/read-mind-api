# API Core - ReadMind AI

Esta API es el núcleo (core) de la plataforma educativa desarrollada para mi tesis, diseñada para conectar con una aplicación móvil en **Flutter**. El sistema permite la gestión integral de entornos de aprendizaje, facilitando la interacción entre roles (estudiante, docente, administrador y superuser) y potenciando el estudio de idiomas mediante herramientas de Inteligencia Artificial generativa.

## 🚀 Características principales
* **Gestión de Usuarios y Roles:** Control de acceso jerárquico (Admin, Superuser, Docente, Estudiante).
* **Gestión de Cursos:** Administración centralizada de grupos y contenidos.
* **Módulos de IA (Gemini API):**
    * **AI Reading:** Generación de paráfrasis, ideas principales y resúmenes a partir de texto docente.
    * **Flashcards:** Creación automática de vocabulario para refuerzo pedagógico.
* **Analytics:** Sistema de seguimiento de progreso del estudiante y estadísticas detalladas para el docente.

## 🛠 Stack Tecnológico

* **Runtime:** Node.js vv24.13.1
* **Framework:** Express
* **Base de datos:** PostgreSQL
* **Autenticación:** JWT
* **Integración IA:** Google Gemini API
